# Pomodoro Study Planner

A minimalist, bilingual (English & Arabic) Pomodoro Study Timer, Schedule Builder, and Distraction Parking Lot web application ready for GitHub Pages.

## Features
- **Smart Schedule Builder:** Enter a start & end time (e.g. `16:00` to `18:30`) or an exact duration (hours & minutes) to auto-generate focus sessions and short/long breaks.
- **Distraction Parking Lot:** Quickly save sudden ideas while studying (`localStorage`) and export them as a `.txt` file later.
- **Installable PWA:** Includes `manifest.json`, Service Worker (`sw.js`), and custom app icons (`icon-192.png`, `icon-512.png`).
- **Warm Minimalist UI:** Light & Dark themes with English (default) and Arabic (`RTL`) support.
